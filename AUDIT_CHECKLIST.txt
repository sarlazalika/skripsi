RINGKASAN TEMUAN TEKNIS
═════════════════════════════════════════════════════════════════════════════

1. PIPELINE UPLOAD (3 TAHAP)
   ├─ Tahap 1: Upload (/upload)
   │  └─ INSERT sesi baru → session_id dibuat
   │  └─ Simpan raw data dengan session_id terikat
   │  └─ Status = 'pending'
   │
   ├─ Tahap 2: Preview (/preview)
   │  └─ Tampilkan preview dari session_id terkini
   │  └─ Pengguna validasi mapping kolom
   │
   └─ Tahap 3: Cleaning (/process_clean)
      └─ DELETE cleaned_transaksi WHERE session_id (re-clean)
      └─ INSERT data bersih dengan session_id terikat
      └─ Status = 'cleaned'


2. PENYEBAB DATA LAMA "TIDAK TERLIHAT"
   ├─ Fungsi get_active_session()
   │  └─ ORDER BY id DESC LIMIT 1
   │  └─ Ambil HANYA sesi terbaru
   │
   └─ Dashboard & Analisis
      └─ WHERE session_id = active['id']
      └─ Hanya tampilkan data dari sesi aktif
      └─ Data dari sesi lama tetap ada tapi tidak ditampilkan


3. STRUKTUR DATABASE
   ├─ upload_session (1 record per upload)
   ├─ cleaned_transaksi (banyak records, grouped by session_id)
   ├─ cleaning_stats (1 record per session)
   └─ raw_data_temp (temp, dihapus >5 sesi lalu)


4. FLOW DATA
   [Upload File] → [session_id baru] → [raw_data_temp]
                                     ↓
                              [Preview Data]
                                     ↓
                        [Process Clean & Validate]
                                     ↓
                    [cleaned_transaksi + cleaning_stats]
                                     ↓
                    [Display di UI - hanya session aktif]

PERTANYAAN: Ketika upload file BARU, apakah data lama dihapus?

JAWAB: ❌ TIDAK

BUKTI:
1. Route /upload hanya INSERT session baru (baris 270-276)
2. Tidak ada DELETE upload_session_old sebelum INSERT baru
3. Data raw disimpan dengan session_id terikat (baris 277-295)
4. Route /process_clean hanya hapus data cleaned UNTUK SESSION TERSEBUT (baris 407-408)
5. Data dari session_id lain TIDAK dihapus
6. Fungsi get_active_session() HANYA ambil session TERAKHIR (baris 104-110)
7. UI dan analisis HANYA tampilkan data dari session aktif (baris 128-132, 512-561, 564-595)
8. clear_data.py TIDAK dipanggil otomatis (hanya manual)
